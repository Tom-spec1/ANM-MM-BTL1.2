# Thư viện và công nghệ sử dụng

- Flask - Web framework cho Python.
- cryptography - X.509 certificate, CRL, OCSP, serialization và asymmetric cryptography.
- OpenSSL - kiểm tra CSR, certificate và các thao tác PKI hỗ trợ.
- SQLite - cơ sở dữ liệu trạng thái nội bộ.
- Bootstrap - giao diện quản trị Web.

Phiên bản cụ thể được khóa trong `requirements.txt` khi áp dụng.
